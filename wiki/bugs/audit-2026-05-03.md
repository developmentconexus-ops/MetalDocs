### A1 + A2 detail — Freeze nil panics

**Files:**
- `internal/modules/documents/application/context_builder.go`
- `internal/modules/render/resolvers/doc_title.go`

`ResolveInput.ControlledDocumentID` never populated → `{doc_code}` resolver calls registry with empty string → no rows.
**Every document approval dies at freeze.**

### A3 detail — Process-area capabilities wiped

**Files:**
- `migrations/0165_role_capabilities_reseed.sql`
- `internal/modules/iam/authz/authz.go`

Migration 0165 does `TRUNCATE role_capabilities` then only re-seeds `viewer/editor/author/approver/system_admin`. Legacy process-area roles (`signer`, `area_admin`, `qms_admin`, `reviewer`) now have zero capabilities. `authz.Require` joins `role_capabilities ↔ user_process_areas` → 403 for every non-admin user. The new `system_admin` bypass masks this only for admin.
**Fix:** New migration after 0165 that re-inserts caps for missing roles, or unify role names across both tables.

## Cross-cutting observations (not fixing now)

- **Document families have no tenant isolation** — global table, any tenant can rename families another tenant uses. Long-term: add governance or make families system-managed.
- **`locked_at` column is dead code** — added in 0131/0167, zero Go references. Drop in future migration.
- **`finalized` status in CHECK constraint is unreachable** — legacy value. Drop in future migration.
- **Two area membership code paths** (`area_membership.go` SQL functions vs `AreaMembershipService` direct writes) — maintenance hazard. Pick one.
- **`RegistryService.Create` has nil-DB branch** with sequence leak on failure — remove nil branch.
- **Fanout client uses `http.DefaultClient` with no timeout** — hung docgen-v2 stalls all signoffs. Add 60s timeout.
- **`composition_config` wrapped twice as `json.RawMessage`** — dead code wrapper, harmless but confusing.
