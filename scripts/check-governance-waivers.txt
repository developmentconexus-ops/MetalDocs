# line. Each check inspects `git diff base...HEAD` (or the equivalent
# merge-base diff) of this file, never its merged contents. Merged entries
# below are permanent audit records — they waive nothing for later PRs. Every
# PR that needs a waiver adds its own line, which the PR reviewer sees in the
# diff and can contest.
