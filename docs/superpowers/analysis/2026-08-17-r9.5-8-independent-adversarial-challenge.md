### Group 1 — Hold-scope boundary semantics (attacks on F5)

**B1 — LOW / OBSERVATION.**
CLAIM: an actor holding `dossier.manage` (author bundle, packet §5.3) may unlink a Document from a held Dossier; retention subjects created *after* the unlink never enter the held set.
EVIDENCE: packet F5 ("unlinking … do not release **already-materialized** held subjects" — prospective capture ends at scope exit); ledger R9.5-5 hold scope rules.
ROOT CAUSE: hold scope is the stable Dossier, not a custodian graph — a deliberate scope-semantics choice, matching the Purview precedent the packet itself cites.
TARGET INVARIANT: invariant 8 reads "prevents disposal of every governed retention subject **within its live scope**" — a post-unlink subject is outside scope, so the invariant is **not** violated.
WHY THE MODEL SURVIVES: direct Document-scope LegalHold is the existing, correct seam for custodian-targeted preservation; unlink is an audited governed mutation; disposal still requires retention expiry + `disposition.manage` + no active hold.
SMALLEST NECESSARY CHANGE: none required. Optional non-blocking note on promotion: surface unlink-under-active-hold events in the audit/timeline projection (already inside R10 obligations 8/11 territory).
DECISIONS MATERIALLY IMPLICATED: none.

**B2 — LOW / DECLARED DEFERRAL.**
Never-submitted DRAFT content of a held Document is outside hold coverage (ledger R9.5-5: hold covers "confirmed governed record content, not transient autosaves/staging"). This is not a hidden gap: eDiscovery/ESI preservation is an explicitly deferred trigger (packet §6, handoff deferred list). No change.

### Group 2 — WorkingContent replacement holism (attacks on F1/F2/F3 jointly)

**B3 — LOW / WORDING.**
CLAIM: if "replace" were implemented as a primary-Artifact pointer swap, stale `structured_authoring` state and its decision-relevant provenance could ride into a Submission that is coherent *by version* (same `working_version`) but semantically divergent (raw uploaded DOCX + leftover structured state).
EVIDENCE: F2 makes structured state a WorkingContent component; F1 guards only same-version snapshotting.
ROOT CAUSE: F1 states snapshot coherence; component disposition under partial replacement is implicit.
TARGET INVARIANT: exact-Submission coherence (core invariant 3).
WHY THE MODEL SURVIVES: F3 already defines replacement at the **WorkingContent** level ("replace its current WorkingContent"), and F2 states structured state is "absent when the chosen format/authoring model does not need it" — holistic replacement dispositions the structured component. Template *seeding* provenance remains historically true regardless (R3–R5 binds seeding, not current-content faithfulness).
SMALLEST NECESSARY CHANGE: when promoting the freeze, fold one sentence into the promoted F1/F3 text: *replacement is whole-WorkingContent — a mutation replacing the primary Artifact must also disposition structured authoring state and its decision-relevant provenance in the same OCC step.* Maps directly onto R10 proof obligations 1–2. No new object; no reopen.
DECISIONS MATERIALLY IMPLICATED: none (enforcement wording of the existing exact-Submission invariant).
