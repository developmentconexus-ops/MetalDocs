## 2. Foundation verdict

This unit IS the deferred half.
- **Sound or patch?** The composite-PK direction is the already-ratified global maximum (fork resolved (a) in the charter; 0264 precedent). Building on it is not optimizing inside a patch. AS-2 not triggered for the PK itself.
- **Live-catalog verification of the charter's blast radius (charter demanded it; it HAD drifted):**
  - 3 composite-FK children — confirmed: `approval_routes`, `cd_sequence_counters`, `controlled_documents` (baseline 4161/4241/4289). Untouched by PK swap (PK `(tenant_id, code)` provides the unique index their FKs need).
  - 4 code-only-FK children per charter → **only 3 exist**: `template_drafts` was already dropped by migration `0260_dead_table_drops.sql:71` (MDDM shadow residue). Remaining: `document_profile_governance`, `document_profile_schema_versions`, `document_sequences`.
  - **All 3 remaining are dead tables:** no `tenant_id` column; zero Go references in `internal/`+`apps/` (grep); zero writes anywhere in `db/migrations`, `db/reference-data`, dev-seed (only baseline DDL); created by archive-era migrations (0027/0040-0052/0046); superseded by live equivalents (`document_profiles.governance_class` + `review_interval_days` for governance; `cd_sequence_counters` for sequences).

Precedent: 0260 dropped `template_drafts` on identical evidence. Trade-off: none real — zero readers/writers means zero behavior change; reversal cost is a re-CREATE if a future feature needs them (they'd be redesigned tenant-scoped anyway).
- **Adjacent observation (ESCALATED → hub ruled IN SCOPE 2026-07-16):** `document_profile_template_defaults` — no tenant_id, no FK, PK=(profile_code) global. Hub ruling: same-migration-or-never (0308 destroys the profile_code→tenant derivation a retrofit backfill would need). **FORK 1 verdict on evidence: DROP in 0308.** Reader census: ZERO readers repo-wide — no product Go SELECT, no SQL function/view/trigger in baseline references it (only its own DDL); writers = `metaldocs-e2e-seed` `ensurePODefaultTemplateBinding` (`main.go:99-158`, INSERT ON CONFLICT DO NOTHING, write-only vestige) + archive-era migrations (0054-0066).
