# Plan 6 · Audit-Trail Completeness Sweep + Audit-Module Hardening

> **For agentic workers:** REQUIRED SUB-SKILL: Use `nexus:executing-plans` (or `nexus:subagent-driven-development`) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One canonical sink (`metaldocs.audit_events`). Every regulated mutation emits to it. Audit endpoint gated, tenant-scoped, retention-aware.

**Architecture:** Three workstreams execute in dependency order — WS-A (audit module hardening: gate + tenant_id + retention + error propagation) → WS-B (emission gaps: all regulated mutations now write events) → WS-C (sink consolidation: templates_v2 and taxonomy/registry abandon their private sinks and write through `auditdomain.Writer`). The auth HTTP handler and IAM admin handler are extended with audit writer fields using the same pattern already live in `admin_handler.go:recordAudit`.

**Tech Stack:** Go 1.25 · Postgres · `auditdomain.Writer` port (`internal/modules/audit/domain/port.go`) · `internal/modules/iam/authz` · `internal/platform/bootstrap`

## 6a / 6b Split Decision

**T-004 (tamper-evidence hash chain) is deferred to Plan 6b.**

Reason: a correct hash chain under concurrent writes requires serialization (advisory lock or `SELECT ... FOR UPDATE` on the last row before INSERT). This introduces its own concurrency ADR, test harness, and validation job — scope beyond the emission-completeness goal of 6a. Append-only is already enforced by `GRANT INSERT` (migration 0005). 6a ships safely without T-004.

**Plan 6a closes:** audit T-001 T-003 T-005 T-007 T-010; auth T-002; iam T-005; registry T-002 T-008; taxonomy T-004 T-005 T-010; documents T-005; templates_v2 T-013.
**Plan 6b owns:** audit T-004 (hash chain).

```go
    audit   auditdomain.Writer // added Plan 6 T-002
}

func NewHandler(service *authapp.Service) *Handler {
    return &Handler{service: service}
}

func (h *Handler) WithAudit(w auditdomain.Writer) *Handler {
    h.audit = w
    return h
}

// recordAudit is a best-effort helper; errors are logged, not propagated.
func (h *Handler) recordAudit(r *http.Request, actorID, action, resourceID string, payload map[string]any) {
    if h.audit == nil {
        return
    }
    raw, err := json.Marshal(payload)
    if err != nil {
        raw = []byte("{}")
    }
    traceID := "trace-local"
    if v := strings.TrimSpace(r.Header.Get("X-Trace-Id")); v != "" {
        traceID = v
    }
    tenantID := ""
    // tenant_id is not in context at login time (session not yet established); leave empty for login event
    if sess, ok := authdomain.CurrentUserFromContext(r.Context()); ok {
        tenantID = sess.TenantID
    }
    if err := h.audit.Record(r.Context(), auditdomain.Event{
        ID:           uuid.NewString(),
        OccurredAt:   time.Now().UTC(),
        ActorID:      actorID,
        Action:       action,
        ResourceType: "user",
        ResourceID:   resourceID,
        PayloadJSON:  string(raw),
        TraceID:      traceID,
        TenantID:     tenantID,
    }); err != nil {
        log.Printf("auth audit write failed action=%s actor=%s: %v", action, actorID, err)
    }
}
```
