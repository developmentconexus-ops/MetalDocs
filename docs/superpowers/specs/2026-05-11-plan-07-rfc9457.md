# Plan 7 · RFC 9457 Envelope Rollout

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every non-2xx HTTP response emits `Content-Type: application/problem+json` with RFC 9457 fields (`type`, `title`, `status`, `detail`, `code`, `errors[]`). Frontend `mutationClient.ts` updated to parse the new envelope.

**Architecture:** A single platform helper (`internal/platform/problem/problem.go`) already exists with `problem.New(status, code, title).Write(w)`. The rollout updates each module's local error-writer to delegate to this helper instead of writing its own `{error:{code,message}}` JSON envelope. The `httpresponse.WriteError` helper is updated first so that modules already using it (registry, taxonomy) get fixed for free. Module-local helpers in IAM, auth, documents, approval, audit, templates\_v2 are deleted and replaced with direct `problem.Write` calls.

**Tech Stack:** Go 1.25, `metaldocs/internal/platform/problem`, `net/http`. Frontend: TypeScript, `frontend/apps/web/src/lib/api/problem.ts` (already RFC 9457-aware with `parseProblem`).

## Scope rules (enforced)

- Change error-response **shape only**. Do not alter business logic in any handler.
- Keep existing error code strings as-is (e.g. `"AUTH_UNAUTHORIZED"`, `"conflict.stale_revision"`). Use catalog constants from `codes.go` only where the existing module code already uses them.
- Only new error-mapping allowed: approval T-003 (`domain.ErrNoActiveStage` → 409 `state.instance_completed`) and registry T-007 (`template_invalid` 422 branch).
- Do NOT add new `problem/codes.go` constants beyond the existing set.
- `go test ./...` must stay green after every commit.

	"encoding/json"
	"net/http"
)

func WriteJSON(w http.ResponseWriter, status int, payload any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(payload)
}

func WriteError(w http.ResponseWriter, status int, code, message string) {

package httpresponse

import (

func WriteJSON(w http.ResponseWriter, status int, payload any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(payload)
}

func WriteError(w http.ResponseWriter, status int, code, message string) {
	_ = problem.Write(w, problem.New(status, code, message))
}

func ReadJSON(r *http.Request, v any) error {
	return json.NewDecoder(r.Body).Decode(v)
}

```ts
export async function mutate<TReq, TRes>(
  method: 'POST' | 'PUT' | 'PATCH' | 'DELETE',
  url: string,
  body?: TReq,
  opts: MutateOptions = {},
): Promise<TRes> {
  const idempotencyKey = opts.idempotencyKey ?? uuidv4();
  const ifMatch = opts.ifMatch ?? (opts.resourceId ? etagCache.get(opts.resourceId) : undefined);

  const headers: Record<string, string> = {
    'Content-Type': 'application/json',
    'Idempotency-Key': idempotencyKey,
  };
  if (ifMatch) headers['If-Match'] = ifMatch;

  const res = await fetch(url, {
    method,
    headers,
    body: body !== undefined ? JSON.stringify(body) : undefined,
  });

  const newETag = res.headers.get('ETag');
  if (newETag && opts.resourceId) {
    etagCache.set(opts.resourceId, newETag);
  }

  if (res.ok) {
    return res.json() as Promise<TRes>;
  }

  // Try RFC 9457 problem+json first.
  const prob = await parseProblem(res.clone());
  if (prob) {
    if (prob.status === 401) {
      dispatchAuthExpired(window.location.pathname + window.location.search);
    }
    if (prob.status === 412 && opts.on412 && opts.resourceId) {
      opts.on412(opts.resourceId);
    } else if (prob.status === 412) {
      toast.error('Documento foi alterado. Por favor, atualize a página.');
    }
    throw new ApprovalError(prob.code, prob.status, prob.title);
  }

  // Legacy envelope fallback: { error: { code, message } }
  let legacyBody: { error?: { code?: string; message?: string } } | undefined;
  try {
    legacyBody = await res.json();
  } catch {
    legacyBody = undefined;
  }

  const code = legacyBody?.error?.code ?? `http_${res.status}`;
  const message = legacyBody?.error?.message ?? 'Erro interno';

  if (res.status === 401) {
    dispatchAuthExpired(window.location.pathname + window.location.search);
    throw new ApprovalError('authn.expired', 401, 'Não autorizado');
  }

  if (res.status === 412) {
    if (opts.on412 && opts.resourceId) {
      opts.on412(opts.resourceId);
    } else {
      toast.error('Documento foi alterado. Por favor, atualize a página.');
    }
    throw new ApprovalError(code, 412, message);
  }

  if (res.status === 429) {
    throw new ApprovalError('authn.rate_limited', 429, 'Muitas tentativas. Aguarde 30 segundos.');
  }

  throw new ApprovalError(code, res.status, message);
}
```

> **Note:** `ApprovalError` constructor takes `(code, status, message)` — the legacy three-arg form. `ApiError` already supports this via `fromLegacy`. `ApprovalError extends ApiError` so this works.
