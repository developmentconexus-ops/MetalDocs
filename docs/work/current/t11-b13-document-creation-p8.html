Responsável

op44 · condicionado a escopo
Resultado ambíguo após envio. A resposta se perdeu depois de o commit ser possível. A intenção continua sendo uma só: repita com a mesma Idempotency-Key para recuperar o resultado exato. Nunca criamos um segundo documento por causa de uma resposta perdida.
Fronteiras: edição de conteúdo e submissão continuam em B04; aprovação em B06; administração de tipos/modelos em B12; descoberta em B02. O code é alocado pelo servidor — esta tela nunca o escolhe nem o prevê.
