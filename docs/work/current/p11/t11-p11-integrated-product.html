Jornadas completas para operar

  1. Consumo: Home → Biblioteca (buscar/filtrar) → Documento oficial → Histórico.
  2. Autoria: Biblioteca → criar de modelo → Documento em edição (upload, SUBMIT) → Meu trabalho.
  3. Aprovação: Notificação ou Meu trabalho → Caso de governança (decidir/feedback) → Documento efetivo.
  4. Administração de governança: tipos/rota/publicação/modelos → modelo → "Abrir documento" (fronteira → B03).
  5. Acesso & organização: Organização (usuário/área/grupo) → Acesso (grants por área/grupo/função).
  6. Evidência: Auditoria (query assist, travessia op78).

Cada rota tem hash próprio (ex.: #/admin/access); recarregar a página preserva o bloco ativo — teste F5 em qualquer rota.

Costura R1 (conhecida): dentro de cada bloco, os terminadores de fronteira ("continua em Bxx") permanecem os do Evidence LOCKED — nesta montagem R1 os blocos estão byte-a-byte intactos, então a travessia entre blocos usa esta navegação global. Converter terminadores internos em navegação real exige um shim de integração por bloco (candidato para R2, sob decisão do operador: fidelidade absoluta vs. travessia embutida).
